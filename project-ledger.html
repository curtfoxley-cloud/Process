      How saving works
      • Save file downloads everything as a .json file; Open file loads it back. Nothing is kept in the browser, so save before closing the tab — you'll get a warning if you have unsaved changes.
      • Save PDF opens the print dialog; pick "Save as PDF" as the destination. It prints the period on screen, charts and wins included.
      • Copy summary puts a plain-text version on your clipboard for pasting into email or chat.
