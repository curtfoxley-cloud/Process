How to use this editor

This editor runs in your browser. It needs no internet connection and installs nothing. Your work saves itself in this browser as you go. Save a project file to keep a copy you can move or share.

Edit a figure from the guidance documents

Pick the figure from "Open a document figure." Change what you need. Click Export PNG.

To put the new image into Word, right-click the old image and choose Change Picture, then From a File. Word keeps the size and position.

Select and move

ClickSelects a shape. A box and its label move together as a group.
Alt + clickSelects one piece of a group, such as just the label.
Ctrl + clickAdds a shape to the selection, or removes it.
Drag empty spaceDraws a selection box. Shapes fully inside it are selected.
Shift + dragDraws a selection box even when you start on top of a large panel.
Arrow keysNudge by 1 unit. Hold Shift to nudge by 10.
Double-click textOpens the text for editing in the panel on the right.

Draw

Box, card, pill, diamondDrag on the canvas to set the size. A click makes a default size.
TextClick where the text should start. Type in the panel on the right.
Arrow and lineClick each corner point. Double-click or press Enter to finish. Esc cancels. "Right angles" keeps each segment level or upright.
Edit an arrowSelect it and drag its points. Double-click a segment to add a point. Double-click a point to remove it.
Model elementDraws a SysML-style box with a stereotype, a name, and a property list.

Style

The style buttons apply the guidance document colors. Engineering is blue. Maintenance is orange. Training is teal. Warning is amber. They change fill, outline, and text together.

The swatches apply one color at a time. Choose Fill, Outline, or Text first.

Keyboard

V R C P D O T A L E BSelect, box, card, pill, diamond, oval, text, arrow, line, model element, badge.
DeleteDeletes the selection.
Ctrl + Z, Ctrl + YUndo and redo.
Ctrl + C, Ctrl + V, Ctrl + DCopy, paste, and duplicate.
Ctrl + G, Ctrl + Shift + GGroup and ungroup.
Ctrl + ASelects everything.
[ and ]Send back and bring forward.
+ and -Zoom in and out.

Files

Save projectSaves an editable .json file. Open it later with Open file.
Open fileOpens a project file, or any SVG. SVG shapes become editable pieces.
Export PNGMakes an image for Word or PowerPoint. 2x suits print.
Export SVGMakes a vector file. PowerPoint can convert it to editable shapes.

Fonts

Figures use Calibri for labels and Cambria for headings, the same fonts as the documents. On a computer without them, the editor substitutes a similar font. Export on a computer with Calibri for the closest match.
