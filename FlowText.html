The basics

egg -> chicken

Each name becomes a box. The arrow -> draws a line with an arrowhead. You can also type leads to instead of ->. Chain as many as you like: a -> b -> c.

Rows (actors)

Customer: Place order -> Clerk: Check stock

The word before the colon is the actor. Each actor gets its own row. After a box has a row, you can refer to it by its name alone. A box with no actor takes the row of the box before it.

To set the row order, add a line: lanes: Customer, Clerk, Warehouse

All the rules

a -> bSolid arrow
a leads to bSame as ->
a -yes-> bSolid arrow with a label
a ..> bDashed arrow
a ..maybe..> bDashed arrow with a label
In stock?A name that ends in ? becomes a diamond
startStart circle. Optional.
endEnd circle. Optional. Each row gets its own end circle.
title: My processTitle at the top
lanes: A, B, CRow order. Rows with no boxes still show.
# noteComment line. Not drawn. // also works.
Line one\nline twoForces a line break inside a box

A full example

title: Order fulfillment
lanes: Customer, Sales, Warehouse
start -> Customer: Place order -> Sales: Check stock -> In stock?
In stock? -yes-> Warehouse: Pick items -> Customer: Receive order -> end
In stock? -no-> Sales: Offer substitute ..retry..> Place order

Tips

Names match without regard to capital letters. "Pick items" and "pick items" are the same box.

A colon splits the actor only when a space follows it. So Meet at 10:30 stays one name.

Click a box in the preview to jump to its line.

Save writes a JSON file with your text and settings. Open reads it back. Open also reads plain .txt files.

Your work is also kept in this browser between visits. Save a file to be safe.

The PowerPoint button makes a .pptx file. Every box, diamond, circle, row and line is a real PowerPoint shape you can edit. "Fit 16:9 slide" shrinks the diagram to fit a normal slide. "Actual size slide" keeps the text size and makes the slide as big as the diagram. Lines do not follow boxes you move in PowerPoint. Make big layout changes here, then export again.

Copy picture and PNG paste into PowerPoint as a single picture. SVG stays sharp at any size, but it needs the font installed on that computer. IBM Plex also needs to be installed for the .pptx to show it.

Keys: F1 shows or hides this help. Ctrl+S save, Ctrl+Shift+S save as, Ctrl+O open.
